## Hosting & Privacy

This documentation site is a static website hosted via **GitHub Pages** (GitHub, Inc. / GitHub B.V.).

- **Server logs:** When you access pages on `kmpkt.io`, GitHub Pages processes technical access data (such as your IP address, timestamp, and requested path) in server logs to deliver the site and maintain security. Details are covered in the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
- **No tracking or cookies:** This site sets no tracking cookies and uses no analytics, advertising trackers, or external third-party fonts. Local browser storage (`localStorage`) is used solely to remember your chosen theme preferences (dark/light mode and optional color palette).
